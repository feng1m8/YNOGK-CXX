# Extra dependencies
This directory contains extra dependencies used in this project.

## solve2345
- **Author**: Wilco Oelen
- **Summary**: The solvers for quadratic, cubic, quartic and quintic equations.
- **License**: [CUSTOM](https://woelen.homescience.net/science/software/index.html)
- **Homepage**: https://woelen.homescience.net/science/math/exps/accurate_solving/index.html
- **Reference**: W. Oelen, [Fast, robust, and accurate low-rank *LDL^T^* quartic equation solver](https://woelen.homescience.net/science/math/exps/accurate_solving/quarticldlt.pdf), 2023.

## Fukushima's elliptic integrals and elliptic functions
- **Author**: Toshio Fukushima
- **Summary**: Precise and fast computation of elliptic integrals and elliptic functions.
- **License**: 
  - [CC-BY-SA-4.0](https://creativecommons.org/licenses/by-sa/4.0/): xcei2.txt, xelbdj2_all.txt, xqcei.txt
  - [CUSTOM](https://doi.org/10.1109/ARITH.2015.15): xgelbd.txt, xgelf.txt, xgscd.txt, xicelke.txt
- **Homepage**: [xcei2.txt](https://doi.org/10.13140/RG.2.2.21737.21607), [xelbdj2_all.txt](https://www.researchgate.net/publication/335109652_xelbdj2txt_Fortran_test_driver_for_elbdj2_upgraded_version_of_subroutine_to_compute_the_double_precision_general_incomplete_elliptic_integrals_of_all_three_kinds_which_is_now_including_celbdj_new_subr), [xqcei.txt](https://doi.org/10.13140/RG.2.2.18830.69443), [xgelbd.txt](https://www.researchgate.net/publication/233942672_xgelbdtxt_Fortran_program_package_to_compute_the_general_incomplete_elliptic_integrals_of_the_2nd_kind_Bphim_and_Dphim), [xgelf.txt](https://www.researchgate.net/publication/233903367_xgelftxt_Fortran_program_package_to_compute_the_incomplete_elliptic_integral_of_the_1st_kind_Fphim), [xgscd.txt](https://www.researchgate.net/publication/233903220_xgscdtxt_Fortran_program_package_to_compute_the_Jacobian_elliptic_functions_snum_cnum_dnum), [xicelke.txt](https://www.researchgate.net/publication/262729893_xicelketxt_Fortran_program_package_to_compute_the_inverse_complete_elliptic_integral_of_the_first_and_second_kind)
